Шрифты для титров (передаются в libass через fontsdir).

- Marck Script — рукописный, для стикеров и подписей (SIL Open Font License, OFL-MarckScript.txt)
- Russo One — жирные заглавные, для стикеров (SIL Open Font License, OFL-RussoOne.txt)

Системный шрифт по умолчанию задаётся REELS_FONT_NAME («DejaVu Sans»).
